# Setup & Installation Guide - Modern Blink Renderer\n\n## Quick Start\n\nThis guide will walk you through setting up the Modern Blink Renderer and testing it with actual websites.\n\n## Prerequisites\n\n### System Requirements\n- **OS**: Linux (Ubuntu 18.04+), macOS 10.13+, or Windows 10+\n- **RAM**: 4GB minimum (8GB recommended)\n- **Disk Space**: 2GB for dependencies\n- **Compiler**: GCC 9+ or Clang 10+\n\n### Install Build Tools\n\n**Ubuntu/Debian:**\n```bash\nsudo apt-get update\nsudo apt-get install -y \\\n  build-essential \\\n  cmake \\\n  git \\\n  wget \\\n  python3 \\\n  pkg-config \\\n  libssl-dev \\\n  libx11-dev \\\n  libxrandr-dev \\\n  libgl1-mesa-dev \\\n  libudev-dev \\\n  libxkbcommon-dev\n```\n\n**macOS:**\n```bash\nbrew install cmake pkg-config\n```\n\n## Step 1: Download CEF (Chromium Embedded Framework)\n\n### Option A: Prebuilt Binary (Recommended)\n\n```bash\ncd modern_renderer\nmkdir -p deps\ncd deps\n\n# Download CEF minimal (Linux example)\nwget https://github.com/chromiumembedded/cef-builds/releases/download/cef_binary_102.0.0%2BgUUID%2Bchromium-102.0.5005.61_linux64.tar.bz2\n\ntar -xjf cef_binary_*.tar.bz2\ncd cef_binary_*/\n\n# Build CEF library\nmkdir build\ncd build\ncmake ..\nmake -j$(nproc)\ncd ../..\n```\n\n### Option B: Build from Source (Advanced)\n\nSee: https://bitbucket.org/chromiumembedded/cef/wiki/MasterBuildSetup\n\n## Step 2: Build the Modern Renderer\n\n```bash\ncd modern_renderer\nmkdir build\ncd build\n\n# Configure with CEF path\ncmake .. \\\n  -DCEF_ROOT=$(pwd)/../deps/cef_binary_102.0.0+gUUID+chromium-102.0.5005.61_linux64 \\\n  -DCMAKE_BUILD_TYPE=Release\n\n# Build\nmake -j$(nproc)\n```\n\n## Step 3: Verify Installation\n\n```bash\n# Run tests\n./renderer_test\n\n# Expected output:\n# === Modern Blink Renderer Tests ===\n# Testing DOMAdapter...\n#   ✓ HTML4 <center> -> <div>\n#   ✓ HTML4 <font> -> <span>\n# Testing CSSProcessor...\n#   ✓ CSS parsing and modernization\n# Testing RendererBridge...\n#   ✓ HTML parsing, layout, and painting\n# All tests passed! ✓\n```\n\n## Step 4: Run Example Application\n\n```bash\n# Basic rendering example\n./renderer_example\n\n# Expected output:\n# === Modern Blink Renderer for Netscape 5.0 ===\n# Replacing legacy rendering engine with modern Blink/WebKit\n# Parsing HTML...\n# Performing layout...\n# Painting...\n# === Rendering Metrics ===\n# Parse time: 2.34 ms\n# Layout time: 1.45 ms\n# Paint time: 3.12 ms\n# Total time: 6.91 ms\n```\n\n## Complete Build Script (Automated)\n\nCreate `build.sh`:\n\n```bash\n#!/bin/bash\nset -e\n\necho \"=== Building Modern Blink Renderer ===\"\n\nSCRIPT_DIR=\"$( cd \"$( dirname \"${BASH_SOURCE[0]}\" )\" && pwd )\"\ncd \"$SCRIPT_DIR\"\n\n# Download CEF if not present\nif [ ! -d \"deps/cef_binary_\"* ]; then\n    echo \"Downloading CEF...\"\n    mkdir -p deps\n    cd deps\n    \n    # Detect OS\n    if [[ \"$OSTYPE\" == \"linux-gnu\"* ]]; then\n        CEF_URL=\"https://github.com/chromiumembedded/cef-builds/releases/download/cef_binary_102.0.0%2BgUUID%2Bchromium-102.0.5005.61_linux64.tar.bz2\"\n    elif [[ \"$OSTYPE\" == \"darwin\"* ]]; then\n        CEF_URL=\"https://github.com/chromiumembedded/cef-builds/releases/download/cef_binary_102.0.0%2BgUUID%2Bchromium-102.0.5005.61_macosx64.tar.bz2\"\n    fi\n    \n    wget -q \"$CEF_URL\" -O cef.tar.bz2\n    tar -xjf cef.tar.bz2\n    rm cef.tar.bz2\n    cd ..\nfi\n\n# Build\necho \"Building...\"\nmkdir -p build\ncd build\n\nCEF_ROOT=$(ls -d ../deps/cef_binary_* 2>/dev/null | head -1)\n\ncmake .. \\\n    -DCEF_ROOT=\"$CEF_ROOT\" \\\n    -DCMAKE_BUILD_TYPE=Release\n\nmake -j$(nproc)\n\necho \"\"\necho \"✓ Build complete!\"\necho \"Run tests: ./build/renderer_test\"\necho \"Run example: ./build/renderer_example\"\n```\n\nMake executable and run:\n```bash\nchmod +x build.sh\n./build.sh\n```\n\n## Testing with Real Websites\n\n### Test 1: Load a Modern Website\n\n```cpp\n// 'CefInitialize'`\n**Solution**: Make sure CEF_ROOT is set correctly during CMake\n```bash\ncmake .. -DCEF_ROOT=/full/path/to/cef_binary\n```\n\n### Issue: CEF binary not found\n**Solution**: Download correct version for your OS\n```bash\n# Check your OS\nuname -m  # x86_64, arm64, etc.\nuname -s  # Linux, Darwin, etc.\n```\n\n### Issue: Out of memory during build\n**Solution**: Reduce parallel build jobs\n```bash\nmake -j2  # Instead of -j$(nproc)\n```\n\n### Issue: X11 or display issues (Linux)\n**Solution**: Run in headless mode\n```bash\nexport DISPLAY=\nxvfb-run ./renderer_example\n```\n\n## Next Steps\n\n1. **Integrate with Netscape**: Link the renderer library into Netscape codebase\n2. **Test Legacy Pages**: Verify old HTML4 pages still render\n3. **Add
